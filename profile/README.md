## 💉 INJECTION TOOLS — `INJECT → MENU → PLAY`

Tools for injecting mod menus and trainers that don't use a launcher.

- **IronInjector** — Included with LKtrainer for PBZ. Open the game, click IronInjector, and wait for the menu to appear [reference:4]
- **UE4SS** — Required for DesertLink Ultimate Mod Menu and other UE4SS-based mods. Install UE4SS, place mod folders in `Steam\steamapps\common\PBZ\platform\steam\ue4ss\Mods`, launch the game and load a save, then press Insert or LT + D-Pad Up [reference:5]
- **version.dll (GlossTrainer)** — Copy `version.dll`, `version.ini`, and the `scripts` folder into `platform/steam` alongside `PBZ.exe`. Start the game normally [reference:6]
- **PBZ-FrameworkMenu** — A UE4SS C++ DLL framework menu opened with **F8**. Independent DirectComposition overlay, safe with FSR3 frame generation. Mods register their own pages and settings [reference:7]

`INJECT → MENU → PLAY`
